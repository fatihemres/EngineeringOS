# Third-party software and content registry

EngineeringOS **original Public Core material** is intended to be distributed under [Apache-2.0](LICENSE), as explicitly selected by the Product Owner on 2026-11-02. This license applies only to material whose rights the EngineeringOS contributors can grant; it **does not** license third-party projects just because their metadata or links appear here.

No third-party tool source code, skill directories, model weights, copyrighted media, binary installers or dependencies are bundled in the Foundation v0.1 source package. Capability registry links are metadata and evaluation candidates. Before bundling, forking or programmatically installing any external capability, verify source owner, exact commit/tag, license, redistribution terms, dependency tree, install hooks, network and update policy. Preserve original attribution/NOTICE requirements and report unknown or incompatible rights as a blocker.
