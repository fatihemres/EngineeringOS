# End-to-End Engineering Feature (proposed)

Scope → project authority/live refs → affected subsystems → two independent proposals where beneficial → structured objections → coordinator synthesis → PO approval → branch/worktree implementation → verified testing → independent review → CI/real acceptance → separate integration decision → dated experience record → optionally sanitized upstream PR.

Every handoff records role, actual actor/session/harness, source and task/fixture SHAs, changed files, run commands, evidence categories, unresolved dissent and who may authorize the next side effect. Do not equate multiple skill prompts in one context with independent agents.
