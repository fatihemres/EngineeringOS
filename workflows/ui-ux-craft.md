# UI/UX Craft Workflow (proposed)

1. Establish real user journeys and current screenshots with provenance; define aesthetic intent, density, themes, motion and accessible behavior.
2. Independently propose 2–3 distinct art/interaction directions (e.g. Taste and UI/UX Pro Max perspectives); avoid presenting one tool's marketing as proof of quality.
3. Assemble an actual prototype with suitable components, design tokens and animation library choices. Measure keyboard, focus, contrast, responsive, low-motion, state persistence, i18n and performance.
4. Independent critique (e.g. Impeccable + reviewer) and PO aesthetics evaluation. Preserve dissent; don't pick a 'winner' from unequal fixtures.
5. Optional final Ponytail code-simplicity review only after the intended product experience is frozen; verify it does not remove intentional states, motion, accessibility or extensibility.
6. Recheck browser + applicable native desktop UI, tests and exact build SHA. Record relevant improvements/failures in project-private experience ledger. Production merge only with appropriate project owner approval.
